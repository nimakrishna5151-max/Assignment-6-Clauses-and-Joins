# MySQL Assignment 2 -- Querying Data
### 1. Retrieving and Filtering Data

-   `DISTINCT` -- retrieve unique salary values from the `Employees`
    table.
-   `AS` (Aliases) -- rename the `age` and `salary` columns as
    `Employee_Age` and `Employee_Salary`.
-   `WHERE` and comparison operators -- filter employees based on salary
    and hiring date.
-   `UPDATE` -- fill a missing designation with `Data Scientist`.

### 2. Sorting and Grouping Data

-   `ORDER BY` -- sort employees by department ID in ascending order and
    salary in descending order.
-   `LIMIT` -- display the first five employees hired in 2018.
-   Aggregate functions -- calculate the total salary in the Finance
    department and the minimum employee age.
-   `GROUP BY` -- find the maximum salary by location and the average
    salary for designations containing the word `Analyst`.
-   `HAVING` -- identify departments with fewer than three employees and
    locations where female employees have an average age below 30.

### 3. Joins

-   `INNER JOIN` -- retrieve employee names, designations, and
    department names for employees assigned to a department.
-   `LEFT JOIN` -- list all departments and their employee counts,
    including departments with no employees.
-   `RIGHT JOIN` -- list all locations and their assigned employees,
    showing `NULL` when a location has no assigned employee.
